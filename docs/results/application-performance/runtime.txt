## Where model loading spends its time (one sampled start of each server)

/usr/bin/sample at 1 ms intervals; counts are main-thread samples, not exact milliseconds.

### cpu
   8100  server_context_impl::load_model
   7959    weight loading: ggml_backend_cpu_repack_buffer_set_tensor
   4383      repack_q8_0_to_q8_0_4_bl calling memmove/memcpy
   3574      repack_q8_0_to_q8_0_4_bl own code

### kleidiai
  22409  server_context_impl::load_model
  21868    weight loading: ggml_backend_cpu_kleidiai_buffer_set_tensor
  15937      tensor_traits::repack own code, most often at +1496 and +1188
   5779      tensor_traits::repack calling kai_run_rhs_pack_nxk_qsi8cxp_qsi8cx_neon

In the pinned library, repack +1188 is in a scalar loop that finds each row's largest
absolute value; +1496 is in a scalar loop that rescales, rounds (fcvtas), clamps and
stores each weight with that single row scale. The pack call is KleidiAI's layout step.
Both conversions also make the first read of the memory-mapped weights; on CPU that
read happens in memmove/memcpy.
